# 项目概览

## 产品目标

为缅甸语学习者提供可安装、可离线使用的背单词 Web 应用，覆盖词书解锁、章节学习、闪卡复习、生词收藏和学习进度同步。

## 当前主要流程

1. 用户注册或登录。
2. 首页浏览词书；免费词书直接进入，付费词书通过激活码解锁。
3. 进入词书章节，下载并缓存章节数据。
4. 在闪卡流程中学习，进度优先写入本地并在联网时同步。
5. 完成章节后更新连续学习信息，可生成打卡海报。

## 产品边界

- 交付形态：Next.js Web / PWA，不维护独立原生客户端。
- 云端能力：Supabase 身份、PostgreSQL 数据与资源服务。
- 离线能力：已缓存章节可学习；需联网的登录、解锁和首次下载不承诺离线可用。
- 前端基线：现有移动端布局、导航和学习交互默认保持不变。

## 当前页面入口

- `/`：首页与词书列表
- `/books/[bookId]`：章节列表
- `/study/[chapterId]`：章节闪卡学习
- `/study/[chapterId]/complete`：章节完成页
- `/vocabulary`：生词本
- `/settings`：设置与缓存管理
- `/login`、`/register`：身份入口

更细的实现细节应直接查看对应路由代码，避免在这里复制易过期的组件说明。

# 发布与回滚清单

## 发布前

- [ ] 目标环境、域名和公开范围已确认。
- [ ] 当前任务满足 Definition of Done。
- [ ] Git 工作区没有无关或未确认改动。
- [ ] 环境变量完整且密钥未进入前端或仓库。
- [ ] 数据库迁移按新增文件执行，RLS 与旧客户端兼容。
- [ ] 构建通过，核心真实页面流程通过。
- [ ] 已记录发布前 Git 提交和当前云端版本。
- [ ] 用户已授权外部发布。

## 发布后

- [ ] 首页返回成功并加载主要内容。
- [ ] 注册、登录和退出流程可用（涉及身份变更时）。
- [ ] 本次新增页面可通过真实入口到达。
- [ ] 核心点击、输入、刷新与返回流程正常。
- [ ] 旧功能与旧数据没有明显回归。
- [ ] 记录部署 URL、时间和版本 ID。

## 回滚记录

每次发布在任务文件中填写：

- 代码回滚点：提交号。
- 云端回滚点：部署版本 ID。
- 配置回滚：需要恢复的变量名，不记录值。
- 数据回滚：可逆迁移步骤；不可逆时写明向前修复方案。
- 回滚触发条件：无法登录、核心页面不可用、数据损坏、安全暴露等。
- 回滚后验证：首页、身份流程、核心数据读取和本次受影响页面。

# FEAT-003 学习数据统计

## 状态

- 阶段：已发布
- 关联：今日复习、专项练习

## 已确认事实

- 学习和专项练习均在浏览器本地优先运行。
- 当前单词进度只保留最后一次结果，无法准确呈现每日答题次数。
- 当前线上环境为 Cloudflare Demo。

## 假设与待确认问题

- 假设：首版统计保存在本地设备即可，多设备同步以后单独迭代。
- 问题：暂不增加排行榜或社交比较。

## 背景与用户场景

用户需要看到学习积累和近期趋势，判断是否坚持以及哪些环节需要加强。

## 目标与成功指标

- 首页能进入学习数据页面。
- 页面展示连续学习天数、累计练习、正确率、掌握/学习中数量和最近七天趋势。

## 范围

- 包含：本地答题事件、统计聚合、首页入口、统计页面和空状态。
- 不包含：Supabase 迁移、多设备同步、排行榜、复杂图表库。

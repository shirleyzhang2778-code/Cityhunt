# 练习模式

## 背景

应用已有闪卡复习，但缺少主动回忆与选择题练习。

## 目标

增加看词选义和听音选义两种练习，同时保持现有界面风格。

## 范围

- 包含：首页练习入口、两种四选一练习、即时反馈、练习结果、错题进入薄弱词。
- 不包含：服务端排行榜、语音识别、键盘拼写。

## 实现决定

- 使用本地已缓存章节与生词数据，保证进入后响应迅速。
- 每组最多十题；答错的词进入近期复习，答对的词更新复习间隔。
- 音频缺失的词不会进入听音练习。

## 验收标准

- [ ] 首页可以进入两种练习。
- [ ] 每题提供四个不重复选项和即时正误反馈。
- [ ] 练习结束显示得分并支持再练一次。
- [ ] 构建通过并部署到现有演示站。

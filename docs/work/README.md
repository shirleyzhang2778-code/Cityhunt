# 当前工作区

每个独立功能或修复使用一个 Markdown 文件。文件名采用简短英文 `kebab-case`，完成后移入 `archive/`。

新任务复制 [`TEMPLATE.md`](TEMPLATE.md)，先完成需求准备与影响范围两个闸门，再开始编码。流程依据见 [`../project/development-workflow.md`](../project/development-workflow.md)。

任务文件是需求、实现、测试和发布之间的追踪入口。不要把多个功能持续追加到同一个任务，也不要复制稳定项目知识。

不要在这里存放密钥、账号、用户隐私数据或完整运行日志。

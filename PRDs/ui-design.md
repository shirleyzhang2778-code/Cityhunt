# 前端 UI 设计规范

## 文档信息

- 状态：当前前端视觉基线
- 版本：1.0
- 更新日期：2026-08-17
- 适用范围：移动端优先的 Web / PWA
- 关联文档：[产品 PRD](product.md)、[开发约定](../docs/project/conventions.md)

## 1. 设计目标

- 学习优先：视觉应帮助用户快速识别单词、进度和下一步操作。
- 低干扰：避免过度装饰、复杂层级和一次出现过多选择。
- 手机优先：主要体验围绕单手操作和窄屏阅读设计。
- 一致反馈：相同状态使用相同颜色、圆角和交互反馈。
- 缅甸语可读：缅甸语必须使用项目指定字体栈，不依赖系统字体碰运气。

## 2. 视觉基线

### 2.1 色彩

| Token | 色值 | 用途 |
| --- | --- | --- |
| `canvas` | `#F9FAFB` | 页面背景、浅色图标底 |
| `card` | `#FFFFFF` | 卡片、表单和底部导航 |
| `primary` | `#1F2937` | 主标题、主要按钮、关键数字 |
| `primary-foreground` | `#FFFFFF` | 主按钮文字 |
| `secondary` | `#4B5563` | 次级正文、返回入口 |
| `muted` | `#9CA3AF` | 辅助说明、计数、禁用信息 |
| `border` | `#E5E7EB` | 卡片、输入框和分隔线 |
| `success` | `#10B981` | 认识、正确、成功状态 |
| `danger` | `#EF4444` | 不认识、错误、退出等危险操作 |
| `star` | `#FBBF24` | 收藏状态 |

进度条统一使用：

```text
从左到右：#34D399 → #60A5FA
轨道：浅灰或 canvas
高度：8px
圆角：满圆角
```

不得把 `primary` 黑灰色作为学习进度填充色；首页今日复习和词书进度必须保持相同渐变。

### 2.2 字体

- 缅甸语首选：`Pyidaungsu`。
- 缅甸语回退：`Noto Sans Myanmar`。
- 其他界面文字：系统无衬线字体。
- 缅甸语内容通过 `BurmeseText` 组件或 `font-burmese` 使用统一字体栈。

### 2.3 字号层级

| 层级 | 建议样式 | 示例 |
| --- | --- | --- |
| 页面标题 | `20px / bold` | 词书、生词本、设置 |
| 学习主词 | `30px / bold` | 闪卡缅甸语单词 |
| 卡片标题 | `16–18px / semibold` | 今日复习、专项练习 |
| 正文 | `14–16px` | 中文释义、说明 |
| 辅助文字 | `12–14px` | 进度、计数、提示 |

长文本应保持舒适行高；单词、音标和释义之间使用间距区分，不靠颜色强行区分所有层级。

## 3. 尺寸与布局

### 3.1 页面容器

- 主页面水平边距：`16px`。
- 学习卡片水平边距：`20px`。
- 页面顶部基础间距：`16px`。
- 底部必须预留固定导航与安全区空间。
- 内容以手机单列为基线，不在窄屏使用横向滚动。

### 3.2 圆角与阴影

- 卡片圆角：`24px`。
- 按钮、输入和内部选项圆角：`12px`。
- 卡片默认：浅边框 + `shadow-sm`。
- 可点击卡片按下时轻微缩放；悬停阴影只作为桌面增强，不依赖它表达可点击性。

### 3.3 底部导航

- 固定高度：`64px`，额外包含设备安全区。
- 固定三个入口：词书、生词本、设置。
- 当前项使用 `primary`，非当前项使用 `muted`。
- 专项练习、复习和统计使用首页卡片入口，不随意增加第四个导航项。

## 4. 基础组件

### 4.1 按钮

- 默认高度：`44px`；重要主操作可以使用 `48px`。
- 主按钮：深灰背景、白字。
- 成功按钮：绿色背景、白字，例如“认识”。
- 危险按钮：红色背景、白字，例如“不认识”“退出登录”。
- 描边按钮：白底、浅灰边框、主文字色。
- 禁用按钮降低透明度，并阻止交互。
- 同一操作区只保留一个视觉主按钮。

### 4.2 卡片

- 使用白色背景、浅灰边框、24px 圆角和轻阴影。
- 标题、说明、数据和操作之间保持清晰层级。
- 不在同一张卡片混用多个无关功能。
- 卡片可点击时整个点击区域应有效，图标不能是唯一入口。

### 4.3 输入框

- 必须有可见 Label，不只依赖 placeholder。
- 错误信息紧邻表单并使用 `danger`。
- 提交中禁用按钮并显示进行中文案。
- 密码输入使用浏览器密码类型。

### 4.4 图标

- 使用 Lucide 图标系统。
- 常用尺寸为 16、20、24px。
- 纯图标按钮必须提供 `aria-label`。
- 图标辅助理解，不替代关键文案。

### 4.5 动效

- 卡片翻转和页面内反馈保持短促，约 200–400ms。
- 进度变化使用平滑宽度动画。
- 完章可使用庆祝动效，但不得阻塞按钮。
- 动效失败或关闭时，信息和操作仍必须完整。

## 5. 页面规范

### 5.1 登录与注册

- 内容使用窄宽居中容器，主标题居中。
- 字段顺序遵循邮箱、昵称（注册可选）、密码。
- 主按钮铺满容器宽度。
- 登录/注册互链和忘记密码作为次级入口。
- 错误在表单内显示；加载时按钮文案切换为“登录中…”或“注册中…”。

### 5.2 首页

从上到下保持以下层级：

1. 页面标题“词书”。
2. Banner。
3. 今日复习卡片。
4. 专项练习双卡片。
5. 学习数据卡片。
6. 分类标题与词书卡片。

今日复习卡片包含图标、标题、今日完成、调整目标、渐变进度条、待复习/薄弱词和一个主操作。窄屏下不得出现文字遮挡；数字变化不应引起明显布局跳动。

### 5.3 词书与章节

- 词书卡片显示标题、说明、锁定状态和渐变进度。
- 未解锁词书点击后打开激活交互，不跳转到不可访问章节。
- 章节列表使用单张分组卡片和分隔线，每行显示标题及掌握数/总数。

### 5.4 闪卡学习

- 学习卡片占据主要视口空间，词汇区域垂直居中。
- 正面突出缅甸语，音标和发音为次级信息。
- “不认识/认识”并排，分别使用危险色和成功色。
- 背面信息从释义到备注、例句、图片逐层展开。
- 星标位于卡片右上区域；已收藏使用黄色填充。
- 底部显示当前题号/总数。

### 5.5 今日复习

- 复用闪卡视觉和交互，不创造第二套学习卡片。
- 页面标题明确区分“今日复习”和“薄弱词巩固”。
- 无任务时使用居中空状态卡片，提供返回词书按钮。

### 5.6 专项练习

- 题目卡片顶部显示模式和题号。
- 看词模式突出缅甸语；听音模式使用大号圆形播放按钮。
- 四个选项纵向排列，保证手机点击面积。
- 正确项使用绿色边框/浅绿背景，错误选择使用红色边框/浅红背景。
- 回答前不泄露正确答案；回答后显示结果和下一题按钮。
- 完成页显示得分、再练一次和返回首页。

### 5.7 生词本

- 标题区域在有数据时显示“背诵生词”入口。
- 单词卡片显示缅甸语、音标、中文释义和可选备注。
- 删除按钮与进入学习区域分离，避免误触。
- 空状态说明如何收藏，并提供“去背词”。

### 5.8 学习数据

- 顶部四张指标卡采用两列布局。
- 最近七天使用轻量柱状图，不引入复杂图表样式。
- 没有事件时显示解释文案，不展示误导性趋势。
- 数字使用主文字色，标签使用弱化色。

### 5.9 设置

- 每日目标使用三个等宽选项，选中项使用主按钮样式。
- 清理缓存使用描边按钮；退出登录使用危险按钮。
- 必须说明清理媒体缓存不会删除学习数据。

## 6. 页面状态规范

每个新增页面必须设计并实现以下适用状态：

| 状态 | 要求 |
| --- | --- |
| Loading | 显示明确中文加载文案或轻量占位，不出现空白页 |
| Empty | 说明为什么为空，并提供下一步入口 |
| Error | 说明可执行的恢复动作，保留已有本地内容 |
| Offline | 区分“已缓存可继续”和“首次加载需联网” |
| Disabled | 视觉弱化并真正阻止操作 |
| Success | 即时反馈，并提供清晰下一步 |
| Auth required | 跳转登录，登录后可重新进入主流程 |

## 7. 响应式与可访问性

- 主要验收宽度：320px、375px、390px、430px。
- 交互目标建议不小于 44×44px。
- 颜色不能作为唯一状态表达，应结合图标或文字。
- 文本和按钮应有足够对比度。
- 图片应提供适当 `alt`；装饰图片使用空 `alt`。
- 图标按钮提供辅助标签。
- 页面支持字体放大后基本操作仍可用。
- 缅甸语不得截断关键字形，避免过小行高。

## 8. UI 变更规则

- 当前页面结构、颜色 Token、圆角、底部导航和闪卡交互属于默认基线。
- 新功能优先复用现有 Button、卡片、进度条、BurmeseText 和闪卡组件。
- 修改公共视觉 Token 前必须列出受影响页面并进行回归验证。
- 用户提供截图时，以明确指出的视觉元素为目标，不顺带重做整个页面。
- UI 变更任务必须在计划中写明“修改什么”和“明确不修改什么”。

## 9. UI 验收清单

- [ ] 与本文颜色、圆角、字号和间距基线一致。
- [ ] 320px 宽度没有横向滚动和操作遮挡。
- [ ] Loading、Empty、Error 和 Success 状态已覆盖。
- [ ] 缅甸语字体和字形显示正确。
- [ ] 主要按钮、返回路径和底部导航可通过真实点击完成。
- [ ] 进度条统一使用绿色到蓝色渐变。
- [ ] 新页面没有无理由增加新的视觉体系或导航项。

# PRD 与设计文档入口

本目录把“产品要做什么、界面应该怎样、技术如何实现”分开维护。

## 当前必读

- [`product.md`](product.md)：正式产品 PRD。描述用户、目标、功能范围、业务规则和验收主路径。
- [`ui-design.md`](ui-design.md)：独立前端 UI 设计规范。描述颜色、字体、布局、组件、页面和交互状态。

## 历史参考

- [`development.md`](development.md)：项目早期技术规范与实现指南，包含技术栈、Schema 和实现建议。它用于追溯历史，不代表所有内容仍与当前代码一致。

## 使用规则

- 讨论功能需求时，以 `product.md` 为入口。
- 修改页面或样式时，必须同时读取 `ui-design.md` 和相关前端代码。
- 讨论当前技术实现时，以 `docs/project/architecture.md`、代码和数据库迁移为准。
- 新功能使用 `docs/work/` 中的独立任务文件，不直接把过程讨论追加到这三份长期文档。
